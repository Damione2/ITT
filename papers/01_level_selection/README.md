# Paper 1 — Chern–Simons Phase Selection on L(6,1)

## Status

**Research Note v0.1 — October 2026**

This paper isolates the ITT level-selection problem and records the mathematically conservative result obtained after analysis of the proposed \(\mathbb Z_6\)-equivariant lift.

The paper establishes:

1. The differential Chern–Simons phase of the selected flat sector,
   \[
   Z_k(L(6,1),\rho_1)
   =\exp\!\left(2\pi i k\,\mathrm{cs}(\rho_1)\right)
   =e^{-2\pi i k/6}.
   \]
2. The corresponding cyclic character, relative to the chosen generator \(\zeta\in\mathbb Z_6\),
   \[
   \chi_k^{\rm CS}(\zeta)=e^{-2\pi i k/6}.
   \]
3. A precise obstruction to identifying this character canonically with the stabilizer action on a hypothetical one-dimensional prequantum fiber over the three-dimensional connection sector.
4. The revised ITT-specific selection principle
   \[
   Z_k(L(6,1),\rho_1)=1,
   \]
   from which
   \[
   k\in6\mathbb Z,
   \qquad k_{\min}=6
   \]
   follows using ordinary integer level quantization.

## Logical status

The paper does **not** claim that \(k_{\min}=6\) is a universal theorem of ordinary \(SU(2)\) Chern–Simons theory.

The phase \(Z_k\) is a derived standard Chern–Simons result. The phase-triviality condition is an **ITT-specific postulate**.

The original proposed canonical \(\mathbb Z_6\)-equivariant fiber identification is recorded as an obstruction/no-go result for the presently specified data.
